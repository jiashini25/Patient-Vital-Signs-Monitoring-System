# Patient Vital Signs Monitoring System

## 1. Project Overview
This project is a simple biomedical application developed using the C programming language. It accepts a patient's heart rate and SpO2 readings and checks whether they fall within predefined example ranges.

## 2. Objectives
- To understand basic patient vital-sign monitoring.
- To apply conditional statements in C.
- To display the status of heart rate and SpO2 readings.
- To demonstrate problem-solving concepts in biomedical engineering.

## 3. Technologies Used
- Programming Language: C
- Compiler: OnlineGDB C Compiler

## 4. Input Parameters
- Heart Rate (beats per minute)
- SpO2 (oxygen saturation percentage)

## 5. C Concepts Used
- Variables and data types
- Input and output statements
- Conditional statements (if-else)
- Logical operators
- Basic problem-solving

## 6. How to Run
1. Open `main.c` in a C compiler.
2. Compile and run the program.
3. Enter the heart rate.
4. Enter the SpO2 value.
5. View the generated report.

## 7. Expected Outcome
The program displays the entered vital signs and indicates whether each reading is within or outside the configured example range.

## 8. Disclaimer
This project is for educational purposes only. The example thresholds are simplified and must not be used for medical diagnosis or treatment.
